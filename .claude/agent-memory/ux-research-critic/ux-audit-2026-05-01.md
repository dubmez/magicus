Conducted: 2026-05-01. Full codebase read, all components, all flows traced.

**Critical issues identified:**
1. No loading/error state during LLM generation — user sees "Mapping" button text but canvas is blank. If API fails, page.tsx silently swallows the error and resets stage to idle with no user feedback.
2. "Incomplete" dashed border is triggered by `!w.trigger` but no tooltip or label explains what "incomplete" means on the card. The amber dashed border is subtle enough that users will not notice it, and there's no onboarding pointer to explain it.
3. "Chain →" affordance is invisible unless user opens the detail panel. No canvas-level affordance for connecting cards. Connect mode UI (crosshair cursor + top banner) is the right pattern but getting there requires knowing the feature exists.
4. No empty-canvas state beyond the landing page. After first map, if user is on "My Business" canvas with 0 workflows (edge case: they deleted all), they see a blank dot-grid with no guidance.
5. "Automate it" button in TopBar is permanently disabled (grey) until a card is selected — but there's no tooltip or label explaining why it's disabled. Users will think the feature doesn't work.

**Significant issues:**
6. Theme picker (4 coloured dots in detail panel) has no accessible label except `title` attribute. Keyboard users cannot use it. Tooltip requires mouse hover to appear.
7. Export modal shows only raw markdown — no rendered preview. The automate modal has read/markdown toggle; the export modal doesn't.
8. Multi-select (shift-click) is documented only in a bottom-left hint on the canvas. No affordance elsewhere. Power feature hidden in plain sight.
9. The sidebar "No workflows yet" empty state is italic grey text — too low-contrast and offers no call to action.
10. Voice input: permission denied error is shown as 12px italic grey text below the textarea — easily missed. No persistent indicator that microphone was denied.
11. "Mapping into a butterfly…" copy during generation is charming but provides no progress signal and no time estimate. For slow connections this becomes anxiety-inducing after ~5s.
12. Connections are all labelled "Triggers" by default (hardcoded in handleCreateConnection). The label is editable only by clicking the label pill on the canvas — zero affordance that this is editable.
13. No keyboard shortcut to close the detail panel (Escape is wired only to cancel connect mode, not to close the panel).

**Polish issues:**
14. The "Or explore the demo workflows" skip link on landing uses a right arrow icon but navigates nowhere visible — it sets `started: true` but lands on an empty "My Business" canvas, not the Examples canvas.
15. ChainRegion rename (pencil icon) appears on hover but ChainRegion has `pointerEvents: none` on the outer div — only the label button itself is interactive, making the affordance very narrow to hit.
16. ButterflyCard tools section renders an empty dark pill bar at the foot when `data.tools` is empty — a visual artifact that looks broken.
17. Delete button in detail panel (Trash2) has no confirmation dialog. One mis-click deletes the workflow permanently (localStorage, no undo).
18. The `automateCount` badge in TopBar uses `rgba(235,244,221,0.25)` on a `#547863` background — very low contrast for the number inside.
19. Canvas zoom controls lack keyboard accessibility (no keyboard zoom shortcut).
20. No page `<title>` update when switching canvases — browser tab always reads "Magicus".
